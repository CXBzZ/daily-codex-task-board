# 行业：Docusaurus 文档站迁移、版本治理与发布前 QA ## 市场与小众性 这是中国境内可做的海外英语市场：把客户已有的 Markdown/MDX、侧边栏、图片、版本说明和部署配置，迁移或整理为 Docusaurus 文档站，并在发布前检查构建、死链、版本路由、搜索、域名和预览环境。它小众在于客户通常不是购买泛开发外包，而是在产品发布、开源重构、API 文档改版时购买“文档信息架构 + 静态站工程 + 可复查 QA”的组合。Docusaurus 官方支持版本化、i18n 与静态部署；其官方文档也明确说明版本会复制文档与侧边栏，并增加维护复杂度，因此有真实的迁移与治理工作量。 ## 谁会买、什么时候买 典型客户是开源维护者、5—50 人 SaaS、API-first 工具、开发者教育产品和小型软件工作室。触发场景包括：从 GitBook/旧 Docusaurus/手工 Markdown 迁出；准备大版本发布；文档链接大量失效；需要把“current / latest / archived”版本路线讲清；或把 GitHub Actions 构建与预览变成可验收的发布流程。客户购买的是迁移映射表、可审查的 PR、构建/链接检查结果、预览链接与交接说明，而不是“保证 SEO 或文档增长”。 ## 参与方与工作流 1. 客户指定内容负责人和代码仓库管理员，书面确认资料权属、授权范围、目标版本、托管方式和验收标准。 2. 服务商只读盘点 Markdown/MDX、图片、导航、断链、版本文件、插件、部署与自定义组件，输出范围清单和风险项；复杂 React 组件、身份认证、搜索迁移、生产 DNS 另行报价。 3. 在分支或测试仓库完成内容映射、sidebar/导航、版本策略、重定向表、构建脚本与链接 QA；由客户在自有账户生成或执行生产令牌、域名和发布操作。 4. 以预览站、构建日志、抽样路由、链接清单和已知限制验收；交付 PR、变更日志、回滚说明及短期缺陷修复窗口。 ## 盈利模式与谨慎报价 可按一次性固定范围收费：仅做“20—50 页内容盘点、信息架构/侧栏、迁移 PR、build 与抽样链接报告”的小试单，可从 USD 300—800（按 2026-11-03 中国银行美元折算价 1 USD≈CNY 6.715，约人民币 2,015—5,372 元）验证；含版本策略、自动化预览和较多 MDX 修复的项目，需要按页面数、插件和自定义程度重新报价。也可提供每月 USD 150—500（约人民币 1,007—3,358 元）的有限维护包，例如一次发布窗口、链接报告和约定小时数。以上是用于验证范围和成本的建议报价，不是公开市场均价、收入承诺或可复制月收入。Mintlify 的公开定价页也把 migration services 列为服务项，但未展示通用价目，说明迁移的合理定价通常依赖范围评估。 成本包括英文沟通、审计/返工时间、测试域名与 CI 分钟、截图/录屏、可能的搜索或托管订阅、收款汇兑/平台费用以及中国税费。先把“页数、版本数、语言数、需否生产权限、修复轮次、支持期”写入 SOW，避免固定价被需求膨胀吞没。 ## 入门门槛 技能：英文技术阅读与写作、Git/GitHub、Markdown/MDX、Node.js 构建、基础 HTML/CSS、链接/重定向与静态托管；进阶才涉及 React、i18n、搜索与 CI。设备：可靠电脑、MFA、密码管理器、隔离浏览器配置和稳定网络即可。时间：先用公开开源仓库完成一份迁移演示和 QA 模板，通常需 1—2 周学习与作品准备。资质上没有把此类技术服务设为牌照行业，但不能以“合规认证、法律意见、安全审计”名义销售。 ## 中国境内承接海外市场的执行边界 获客可用 GitHub 开源贡献、技术社群、英文作品集和自由职业平台；交付尽量异步，用 Issue、PR、预览 URL 和验收清单沟通。合同/SOW 应写明客户拥有资料权属，并确认其允许服务商从中国境内按约访问和处理；服务商仅获最小权限，验收后删除本地副本、令牌和预览数据。不要把私有仓库、日志、密钥或含个人信息的内容投入未获客户书面批准的第三方 AI/分析工具。 收款、合同、发票与税务：使用可核验的服务合同、工作说明、交付/验收记录、收款记录及按经营主体情况开具/申报；跨境服务是否适用增值税免税要看服务性质、境外消费等实际条件。国家税务总局明确：符合规定的跨境应税服务可免征增值税但仍须按规定申报，且通常要办免税备案；不能因面对境外客户就自行认定免税。建议以主管税务机关口径和专业人士意见为准。 数据与隐私：客户私有仓库、Issue、访问日志、API 示例及预览环境可能有个人信息、商业秘密或凭据。中国《个人信息保护法》要求最小必要；向境外提供个人信息时还规定相应条件、告知和单独同意等要求。反向情形（海外客户数据让中国境内服务商远程访问）也可能受客户所在地法律、合同、行业规则约束；“使用 GitHub”不等于已完成跨境合规。只接可脱敏、可最小化且有书面授权的项目。语言与时区方面，需能阅读英文技术资料，并为欧美客户预留少量重叠时段；不要承诺 7×24 紧急发布支持。 ## OPC 与数字游民适配度 适合 OPC：审计—迁移—版本策略—构建/链接 QA 可以拆为固定范围、模板化交付，小团队固定资产轻。并非完全适合：多版本文档、复杂自定义 React/MDX、搜索/托管迁移和紧急发布会明显扩大维护责任，应采用变更单和明确支持期限。 适合数字游民：以 Git、Issue、预览和异步验收为主，地点依赖低；前提是可靠网络、设备安全、MFA 与时区管理。涉及生产凭据、敏感数据、受监管行业或现场应急值守的单子不适合。 ## 收益前提、风险与不适合人群 潜在收益取决于英文能力、工程质量、复购与获客成本；试单收入不能等同于稳定月收入。主要风险是范围蔓延、版本/URL 误配导致断链、私有代码或日志泄露、客户无权提供内容、海外工具访问稳定性、收款汇兑及税务判断错误。GitHub Pages 自定义域名需要验证以降低域名接管风险，Docusaurus 部署还涉及基础路径与构建产物，均应先在预览环境核验。 不适合：只会翻译但不能自行构建/排错的人；需要快速高收益承诺的人；无法签署保密/数据处理条款的人；必须处理真实生产 PII、密钥、医疗金融等高敏数据而客户又不能提供最小权限或测试环境的人。 ##
