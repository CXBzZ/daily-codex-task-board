今天的小众行业是面向海外小型 SaaS 与产品团队的 Figma Variables / Design Tokens 盘点、迁移与设计—开发交接 QA，属于中国境内可远程承接的海外市场。它适合用固定范围、客户授权和证据化交付做 OPC/数字游民试单，但不能包装成设计系统、无障碍、安全或法律合规认证。

## 行业是什么，为什么小众 Figma Variables / Design Tokens 服务不是普通 UI 设计，而是为已有 Figma 文件和轻量设计系统做变量、样式、别名、模式与组件绑定关系的盘点、清理、迁移和交接检查。设计 token 是颜色、间距、字号、圆角、阴影等可复用设计决策的命名化数据；Figma 官方说明 Variables 可保存并复用设计属性，并可用于设计系统、原型和 API。 它小众，是因为客户通常只在设计稿颜色/间距漂移、浅深色模式不一致、设计和前端 token 对不上、多人共用库失控或准备迁移时才意识到问题；工作需要同时读设计语义、组件体系、变量别名、DTCG JSON 格式与开发交接语境。它不是“画页面”，也不是承诺自动把 Figma 变成生产代码。 ## 目标市场与客户 目标为中国境内可做的海外英语市场。优先客户是已有 1—3 个 Figma 库、10—80 个页面或少量组件的海外独立开发者、小型 SaaS、产品工作室和软件外包团队；典型触发场景包括品牌改版、浅/深色主题、设计系统初建、交付开发前检查、设计师离职交接，或由旧 styles 迁至 Variables。 为什么可由中国境内 OPC 验证：交付以 Figma 协作、脱敏 token 导出、CSV/JSON、截图、Loom 和英文报告为主，不需要当地门店或牌照；可先售卖只读“token 健康检查”小单。客户必须在其自有 Figma 团队中邀请服务商，不能索要或共享账号。 ## 如何运作：参与方与工作流 1. 销售前限定范围：确认文件/页面/组件数量、是否含多品牌/多主题、是否要改动源库、是否有代码 token、可用计划和协作权限；签 SOW/NDA，写清不审计生产代码或法律合规。 2. 只读盘点：统计本地/库 Variables、styles、原始硬编码值、变量别名链、模式、组件变体、未绑定值、疑似重复和命名冲突；输出风险分级。 3. 方案：和客户确定 primitive（原始色阶/尺寸）—semantic（用途）—component token 的命名与弃用规则，明确哪些仅建议、哪些获批后才可修改。 4. 迁移/修复：在客户批准的分支、测试文件或有限页面中创建/绑定 Variables、修正 mode，或将已批准 token 按 Figma 支持的 DTCG JSON 导入/导出；保留变更日志和回滚点。 5. QA 与交接：抽样切换 mode、检查别名是否断裂、比对选定组件与 Dev Mode 可读性；交付 token 清单、变更记录、未解决项、命名指南和 20—40 分钟交接视频。 Figma 官方文档说明 Variables 支持在设计和开发交接中查看值、别名链和模式；其导入要求使用 DTCG JSON，并对 token 类型、单位、跨 collection 引用和同名归一化有具体限制。因此服务的实际价值是把这些限制变成可复查的清单，而不是声称“无损万能迁移”。 ## 盈利方式与报价口径 可产品化为：(a) 只读 token / variables 盘点与报告；(b) 单一库、指定页面或主题的迁移与 QA；(c) 设计—开发交接包和月度变更巡检。收入来自固定范围服务费、额外页面/组件、加急、交接培训和月度维护；不应靠无限修改或代管客户管理员账户。 公开报价只能作样本，不是平均市场价或个人到手收入：Upwork 上一位资深从业者的 Figma 文件清理/设计系统审计标价为 USD 1,200 / 10 天（其标准、进阶档更高）；挪威设计系统工作室 PXL 的公开起步价为 NOK 1,500 / 小时。两者均是成熟供应商报价，不能直接套用到新手。 新手可将 1 个小文件、只读盘点和报告限定为 USD 150—400；按仅为报价展示而采用的 1 USD≈¥7.1，约为 ¥1,065—2,840。涉及多品牌、多模式、数百组件、代码库同步或大量实际修复时必须先付费勘察再报价。净收入还要扣平台佣金、收款/结汇费用、软件席位、翻译与沟通时间、返工、税费和获客成本；不承诺时薪、利润、就业或客户增长。 ## 入门门槛 技能：英文书面沟通、Figma Variables/Components/Dev Mode、颜色与排版/间距语义、JSON、DTCG 基础、版本与变更记录、需求边界和截图式 QA。设备软件：稳定网络、电脑、Figma 合法席位/客户协作邀请、表格/文本工具和录屏工具。Figma 的 variables library、modes 和 API 可用性受订阅计划影响，售前必须核对客户计划。 资金很轻，但时间门槛不低。可先使用公开社区文件练习 variable 名称、mode 切换和 DTCG JSON；再做 2—3 个非生产模拟审计。没有设计系统经验、无法读英文产品语境、不能解释 alias/mode 与开发交接差异，或想用模板批量“自动修复”的人不适合直接接生产库。 ## OPC / 数字游民适配度 OPC 适配度高于一般定制设计：可用“盘点—小范围实施—QA—交接”的可复制流程，固定资产低，任务可切成按库/页/组件计价。但复杂设计系统需要设计、前端、产品共同决策；一人不应承诺大规模多端 token 重构、完整 code sync 或全天候支持。 数字游民适配度较高：盘点、文档、截图、录屏和异步评审可远程完成。限制是稳定网络、跨时区会议、保密环境和客户文件权限；旅行网络、公共电脑或无法保证删除/加密措施时，不应接含敏感资料的项目。 ##
