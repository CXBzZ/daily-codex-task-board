# 行业：Algolia DocSearch 文档搜索上线服务 ## 1. 是什么，为什么小众 这是为技术文档站配置 Algolia DocSearch 的细分交付：梳理 sitemap 与可抓取页面，配置 Crawler 的 URL 范围、忽略规则和标题层级选择器，检查 crawler 抽取的 record，接入 JS/React/Docusaurus 搜索组件，并以代表性检索词、版本/语言筛选和移动端界面完成上线前 QA。它不是泛 SEO 或全栈开发；客户常已有文档站，却缺少能让开发者快速找 API、版本差异和排障条目的站内搜索。小众之处在于同时要理解文档信息架构、HTML 层级、爬虫 record schema、前端包与验收用例。 目标市场为“**中国境内可做的海外市场**”，优先英语技术文档、开源项目和小型 SaaS。Algolia 官方说明：DocSearch 将 Crawler 与前端体验分开，配置可定义抓取/排除 URL 和内容层级；上线前应试跑爬虫、审查记录并监控后续抓取。 ## 2. 客户、需求与工作流 典型客户：使用 Docusaurus、React、静态站点生成器或自建 docs portal 的海外开源维护者、小型开发者工具/SaaS、技术内容团队。常见触发点：文档已超过几十篇、版本页混入搜索、旧页面仍被索引、结果标题层级不清，或要把站内搜索作为一次文档改版的收尾项。 推荐工作流： 1. 客户提供公开预览站、sitemap、框架版本、目标页面清单和 10–20 个验收查询；先书面确定哪些 URL 能被抓取。 2. 服务商在测试项目或客户最小权限账户中盘点 URL/robots/sitemap/HTML 层级，提出 crawler 与 record 字段建议；客户管理员创建或确认应用、密钥和域名归属。 3. 以测试 crawl 审查结果，接入 `@docsearch/js`、`@docsearch/react` 或 Docusaurus 官方适配方式，完成桌面/移动端和空结果/错误链接检查。 4. 交付配置 diff、URL/查询测试表、截图或录屏、未解决项和回滚说明；生产发布、API key 管理和周期性维护由客户管理员确认。 ## 3. 怎么赚钱、收益口径与成本 可把服务拆为固定范围小单：公开文档站体检 + 10 个查询 QA、单站 crawler/前端接入、或改版后的回归检查；另行报价版本筛选、迁移和月度复测。新手可先以 **US$150–500/单（按 2026-11-24 中国银行美元折算价 1 USD≈¥6.7111，约 ¥1,007–3,356）** 做边界清晰的试单；这是建议测试报价，取决于页面数、框架、客户是否已有 Algolia 项目及返工次数，并非行业均价或收入承诺。 公开对照样本：技术文档专业服务商 TechDocs Studio 在其网页列出搜索审计/修复 US$2,900（约 1 周）和全量搜索部署 US$4,900（约 2 周），且明确订阅费另计；这只能说明成熟的更大范围交付存在付费空间，不能外推为个人可得报价。Algolia 自身费用由客户承担：官方价格页列出免费层含 10,000 搜索请求、100,000 records、10,000 crawls/月等限额；符合条件的 DocSearch 项目免费，但须保留 “Search by Algolia” 标识。 成本结构主要是沟通/时区、测试站或本地构建、必要的代码托管与设计工具；不要把客户的 Algolia 订阅、域名/CDN 或开发改造工时混入服务商营收。单人每月可接多少单取决于需求澄清、返工和售后，不以“月入”倒推承诺。 ## 4. 入门门槛与合规 技能：英文读写与异步沟通、HTML heading/metadata/sitemap/robots、JS 或 React 基础、Git PR、文档信息架构和可复现测试。设备：电脑、浏览器开发工具、GitHub/GitLab、可运行客户文档项目的 Node 环境；通常不需重资产。时间：先用 1–2 个公开开源文档站建立测试 case，再做一单小范围 QA。 Algolia 要求与平台边界：免费 DocSearch 面向技术文档/技术博客，申请及域名验证、免费标识和平台资格由客户负责；若不能展示 logo 或非适用页面，应由客户评估自建 crawler/付费方案。官方还说明爬虫按网页标记提取内容，数据会托管在 Algolia 的全球副本。因此只处理客户明确授权的公开技术文档；内网文档、搜索日志、管理员权限或跨境数据传输，先由客户确认平台资格、数据处理依据与收款/税务路径。服务商不代持 Admin API key、不擅自导出数据，也不接触或留存真实搜索日志。 跨境承接：获客可从 GitHub 开源项目、英文技术社群、作品集/独立站和自由职业平台的公开需求开始；报价与范围需用英文合同/订单写明 URL 范围、验收查询、改动次数、知识产权、保密与数据处理边界。收款使用客户与服务商均可合法使用、能留存合同/订单/交付证据的路径；不绕开平台或外汇规则。税务方面，国家税务总局说明，向境外单位提供且“完全在境外消费”的部分软件服务、信息系统服务等可能适用增值税零税率，但并非自动适用，须按服务性质、实际消费地、资料留存和主管税务机关要求办理；个人/个体户/公司应按自身主体、属地与会计意见申报。语言和北美/欧洲时区会带来 4–12 小时响应错位，宜承诺异步 SLA 而非 24×7 值守。 ## 5. 为什么适合 OPC / 数字游民，及局限 OPC 适配度高：配置、QA、报告和交接可产品化为检查表，小单固定范围、无需线下库存，复杂代码改造可排除或外包。数字游民适配度较高：诊断、配置 review、文档和异步验收可远程完成；但客户发布窗口、英文会议、生产故障和密钥处理不适合边旅行边即时响应。不能把自己包装成 Algolia 官方支持、安全审计、隐私认证、SEO/AI 搜索增长顾问，也不能保证申请获批、爬取稳定、排名、转化或零故障。 主要风险：客户站点把个人信息、内部链接或受版权限制内容误放进抓取范围；管理员 key 泄露；非公开站点违反平台或客户政策；文档结构变化导致搜索回归；跨境数据、收款凭证和税务判断不足。降低方式是公开内容优先、最小权限、客户管理员持钥、测试索引/可回滚发布、禁止把日志下载到本地、用 query/URL 证据验收，并将法律/税务/隐私结论交由客户顾问。 不适合人群：不愿英文写作和异步支持者；无法理解 Git/HTML/前端构建者；希望靠通用模板承诺流量或快速高收入者；或要求服务商代管生产密钥、内网文档和用户日志的客户。 ## 6. 新手低成本验证步骤 1. 选一个许可允许的公开开源文档站或自建 Docusaurus demo，制作 sitemap、heading 层级、10 条检索用例与问题清单，不爬取私有内容。 2. 在自己的测试项目按官方文档跑一次配置/记录审查/前端接入，输出一页英文样例：范围、验收查询、截图、未覆盖项和回滚说明。 3. 以“公开 docs search QA（不拿 Admin key、不承诺增长）”发布 US$150 左右的固定范围试单；先以客户管理员执行权限/发布，自己交付配置建议和复测证据。 ##
