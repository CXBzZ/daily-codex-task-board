合成媒体鉴伪与防护（Deepfake / 合成媒体检测）帮个人、媒体与企业判断音视频图片是否被AI生成或篡改，并出具核验报告。它搜索量低、需求隐蔽、夹在企业级安全公司与免费工具之间的中端空白，一人可异步远程完成、启动成本近零、全球客户，是适合 OPC 与数字游民的小众服务方向。

一、行业是什么，为什么小众 一句话定义：帮个人、企业、媒体机构判断一段音视频 / 图片 / 文本是否由 AI 生成或被篡改（深度伪造检测 + 来源鉴伪），并出具可采信的核验报告与防护建议。 为什么小众：① 搜索量极低——普通人不会搜“deepfake detection service”，只会搜“这是不是假的”“视频是不是AI做的”；② 需求隐蔽在“我妈接到AI语音诈骗电话”“远程面试候选人视频是假的”“要发的新闻图是AI生成的”等具体痛点背后；③ 它夹在免费在线检测器与企业级安全公司（Reality Defender、Sensity、Intel）之间，存在大量中端空白——中小机构、自由职业者、普通人付不起企业方案，也用不好纯工具；④ 技术门槛被高估：实际可用成熟工具 + 人工研判 + 报告交付完成，不必自己训练模型。 二、如何运作 - 典型客户与需求触发：① 自由记者 / 自媒体 / 事实核查者（发稿前核验 viral 图视频）；② 小型政治竞选 / nonprofit（选举前监测伪造音视频）；③ HR / 招聘方（远程面试视频与证件照鉴伪，防朝鲜IT工远程渗透）；④ 普通个人（接到“家人”AI语音勒索、网恋AI头像诈骗时求鉴定）；⑤ 律所 / 保险（证据图真实性、理赔照伪造排查）；⑥ 中小企业（BEC邮件头附件头像鉴伪）。需求大多由“被诈骗、被冒充、要发稿、要招人、要打官司”触发。 - 核心交付物：一份带置信度评分、具体痕迹标注与结论的“媒体真实性核验报告”（含多工具比对、元数据 / EXIF 分析、来源溯源建议），以及可选的“防护清单 / 应对流程”。 - 完整工作流：获客（在 LinkedIn / Upwork / Fiverr 上架 gig、打入记者群 / 反诈群 / HR 社群、做内容营销）→ 接单收素材（客户提供图 / 视频 / 音频）→ 用 2–3 个检测器交叉扫描 + 人工研判（元数据、压缩失真、脸部边界、音画同步、眨眼与微表情、来源反搜）→ 出具报告与建议 → 收款（平台托管或预付 / 里程碑）。 -
